# Amanda Andrade — Portfólio

**Estudante de Engenharia de Software | Desenvolvedora em formação**

Portfólio pessoal desenvolvido para apresentar minha trajetória em Tecnologia, minha experiência profissional, projetos acadêmicos e pessoais e meus objetivos de evolução na área de software.

A interface mantém uma identidade visual inspirada no espaço, com fundo escuro, campo de estrelas, núcleo planetário interativo, detalhes em azul e rosa e cartões com transparência sutil.

## Sobre mim

Sou formada em **Análise e Desenvolvimento de Sistemas** e atualmente curso **Engenharia de Software**. Atuo como estagiária de Engenharia de Software na Secretaria Municipal de Cultura e Economia Criativa.

Tenho interesse em aprofundar meus conhecimentos e construir minha carreira conectando:

- **Python e Back-end:** fundamentos da linguagem, desenvolvimento de APIs e integração de sistemas.
- **Inteligência Artificial:** aplicações com IA, Machine Learning e integração de modelos.
- **Bancos de dados:** SQL, modelagem e gerenciamento de dados.
- **Servidores e infraestrutura:** Linux, redes, Docker e implantação de aplicações.

Meu nível atual em Python é básico; essas áreas representam minha direção de estudo e desenvolvimento profissional.

## Recursos da interface

- Campo de estrelas animado em Canvas.
- Painel espacial com planeta interativo por mouse e toque.
- Animações de entrada com Intersection Observer.
- Navegação responsiva com menu compacto para telas menores.
- Botão para retornar ao topo.
- Respeito à preferência do sistema por movimento reduzido.

## Como executar localmente

Clone o repositório:

```bash
git clone https://github.com/Amanda-AAndrade/amanda-dev-portfolio.git
```

Acesse a pasta:

```bash
cd amanda-dev-portfolio
```

Abra o arquivo `index.html` no navegador ou utilize a extensão Live Server no Visual Studio Code.

O projeto é uma aplicação front-end estática e não exige instalação de dependências para a visualização básica.
